Integration point for the proposal

Replace CandumpLogReader with a native per-line parser in logfile.py, following AscLogReader: same ReplayMessage and LogReadStats, and bad lines are counted and skipped. open_log(), the Django endpoints, the plugin and the Flutter screen keep their current interfaces. The UI already shows unparsable_lines during replay through can_transport_bar.dart.
